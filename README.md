# Weatherly — Weather App Version 2

Personal desktop weather dashboard with free forecast, air-quality, official alert, search, location, saved-place, and live-radar services.

## Run

```bash
npm install
npm run dev
```

Open http://localhost:3000 and allow location permission if you want to use your current position. Browser notifications work while the dashboard remains open.

## Data sources

- Open-Meteo: forecast, geocoding, air quality
- BigDataCloud: current-location naming (reverse geocoding)
- Environment and Climate Change Canada / GeoMet: Canadian official alerts
- U.S. National Weather Service: U.S. official alerts
- RainViewer and OpenStreetMap: live radar and basemap
